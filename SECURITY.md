# Security

Please report a vulnerability privately, through **Report a vulnerability** on this repository's [Security tab](https://github.com/Cynicollision/fretdex/security), rather than in a public issue.

Fretdex is a static site with no backend, and nothing it stores leaves the device. It's maintained by one person in their spare time, so there's no fixed response time. Fixes go into the latest release only.
