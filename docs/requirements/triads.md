# Triads and String Sets (`TRI`)

Major, minor, diminished and augmented triads, in each inversion, on each set of three adjacent strings: the small shapes used for comping and for finding a chord anywhere on the neck. Guitar only, and close-voiced on adjacent strings; sus and spread triads are later (the backlog).

Screens: **Triads** (`/triads`) and the triad card (`/triads/[root]/[quality]`, options `set` 1–4 and `inv`).

## TRI-1 The user can find a triad on any string set

| ID | Requirement | Status |
|---|---|---|
| TRI-1.1 | The list shall offer a root picker and the qualities **Major**, **Minor**, **Diminished** and **Augmented**. | Planned |
| TRI-1.2 | The card shall show, for the chosen string set (`set`: 1 is strings 1–3, 4 is strings 4–6), every voicing of the triad on those strings across the fret range, as a strip of the neck, each labeled with its inversion. | Planned |
| TRI-1.3 | The user can filter to one inversion (`inv`: root, 1st, 2nd) to see where it falls on each set. | Planned |
| TRI-1.4 | On bass, the module shall say it's for guitar and offer to switch instrument for this view (APP-3.3). | Planned |
| TRI-1.5 | Each shape shall play as a block chord when tapped (AUD-2). | Planned |
| TRI-1.6 | Pinned triads shall be listed first (PIN-3). | Planned |
| TRI-1.7 | With no `set` in the URL, the card shall show **All sets**: the four strips stacked. | Planned |
| TRI-1.8 | Shapes shall be computed for the current tuning, so they work in any tuning. | Planned |
